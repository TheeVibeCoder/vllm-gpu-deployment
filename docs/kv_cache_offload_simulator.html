❌ Traditional Attention (Old Way)
ONE giant contiguous KV tensor → [tok1][tok2][tok3]...[tok2048]
  • • One massive contiguous memory allocation
  • • Can't move part of it — all or nothing
  • • Wastes memory (pre-allocates max length)
  • • Can't offload individual pieces
✅ PagedAttention (vLLM — What We Use)
📄 Page 1
16 tok
📄 Page 2
16 tok
📄 Page 3
→ CPU
📄 Page 4
16 tok
  • • KV cache split into fixed-size pages (like OS memory pages)
  • • Each page = 16 tokens × 24 layers × K+V tensors
  • • Pages are non-contiguous — can be anywhere in VRAM
  • • Can move individual pages between GPU ↔ CPU ↔ SSD!
💡 PagedAttention is WHY offloading is possible. Without paging, you'd have to move the entire KV cache at once (too slow). With pages, LMCache moves only the cold ones.
Each page in this simulator = 1 PagedAttention block = 16 tokens of K + V tensors (~195 KB for Qwen2.5-0.5B)
